Copy for sign-in errors and setup states

We couldn’t complete sign-in. Please try again.

Account without access: “This account doesn’t have access yet. Choose an approved Google account.”

Temporary setup issue: “Sign-in is temporarily unavailable. Please try again later.”

Implementation: retain one clear retry action, announce errors to screen readers, and never reveal the owner’s email.

Shared principles: one sign-in action, concise copy, readable contrast, visible keyboard focus, a 48 px sign-in target, and no public workout data.

Reference: Google button guidelines · WCAG contrast · WCAG target sizes · Navigation guidance.

These are visual prototypes, not a production accessibility certification. Final button assets, fonts, focus, error states, and responsive behavior should be checked during implementation.
